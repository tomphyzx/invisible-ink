# Icon

An outlined inkwell, clear so the quill shows through it, with a thin line marking the
level of the ink you can't see. Each version comes with dark lines (for light backgrounds)
and a `-dark` copy with light lines (for dark backgrounds).

| File | Use |
|---|---|
| `invisible-ink.svg` | 128 px and larger: the README, the web page, the GitHub social preview |
| `invisible-ink-simple.svg` | about 32 to 64 px: avatars, app and tab icons |
| `invisible-ink-16.svg` | 16 px, placed pixel by pixel: favicons |

Two rules keep it readable as it gets smaller:

- **The ink line sits halfway** between the shoulder of the well and its base, so the
  clear gaps above and below it stay equal and the line never merges into the outline.
  At 16 px that is a two-pixel line with two clear rows on each side.
- **The quill enters through the neck.** It never crosses the glass, which at small sizes
  would read as a clump of pixels rather than a quill.

Colours: lines `#1f2328` (dark) / `#e6edf3` (light), ink `#2f81f7` / `#58a6ff`.
